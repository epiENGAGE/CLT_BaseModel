Approach

Model

Age-structured SEIR model with a vaccinated arm (SEIR-V), 7 age groups, built and run through a web interface (Python)

Data

Massachusetts weekly admissions, first doses and population, by county and age group, aggregated to the state

Uncertainty

Bayesian MCMC fit; every scenario re-run once per posterior draw, so results carry 95% intervals

The data-preparation scripts can also aggregate counties into groups through a mapping file; this analysis uses the state level. The admissions column in the new data is ed_admits_count.
